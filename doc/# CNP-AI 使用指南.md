# CNP-AI 使用指南

CNP-AI是一个在命令行里直接使用的智能终端助手：读取当前窗口的内容作为上下文，并在独立的执行 pane 中（经确认后）代你执行命令。

## 前置要求

- Unix-like 系统（Linux/macOS）
- 可访问安装脚本与模型服务端点，使用长城云大模型平台的模型服务

> [!NOTE]
> `tmux` 未安装也可以：默认安装脚本已覆盖并处理 `tmux` 缺失的场景。如遇安装失败问题联系 GW00317308
>

## 安装

```bash
curl -kfsSL http://cnpai-cnp-bdtest.gwmit.cn/install.sh | bash
```

- 默认安装到 `/usr/local/bin/cnp-ai`
- 默认安装脚本已配置好模型相关信息，默认模型为：`deepseek-v3-2`

## 快速开始

如果尚未安装 CNP-AI，可先执行：

```bash
curl -kfsSL http://cnpai-cnp-bdtest.gwmit.cn/install.sh | bash
```

1) 进入你的环境或者对应机器

```bash
cd /path/to/your/project
```

2) 启动 CNP-AI

```bash
cnp-ai
```

默认安装脚本已经配置好模型相关信息，默认模型为：`deepseek-v3-2`。

3) 在 聊天窗口 输入你的请求，例如：

- `帮我解释这个错误日志并给出修复步骤`

## 日常使用（窗口/进入/退出）

- 窗口切换
  - 窗格（pane）之间切换：`Ctrl-b` + 方向键
- 调整窗格大小（比例）：
  - `Ctrl-b` 后按住 `Ctrl` 键不放，同时按 `方向键`（上下）可调整当前窗格大小
- 查看屏幕外文字（历史回滚）：
  - 按 `Ctrl-b [` 进入复制模式（Copy Mode）
  - 此时右上角通常会显示行数提示，使用 `方向键`、`PageUp/PageDown` 即可滚动查看历史输出
  - 按 `q` 退出该模式，回到正常命令行输入状态
- 进入项目：建议在目标项目目录下启动 `cnp-ai`，并把与项目相关的命令输出留在同一窗口内，便于 CNP-AI 读取上下文
- 退出项目：在 Chat Pane 输入 `/exit` 结束本次会话

## 工作方式与布局

CNP-AI 以上下分屏作为基础布局，并将当前窗口的 pane 分为两类：
- Chat Pane：你与 AI 交互的地方
- Exec Pane：AI 建议并经确认后实际执行命令的 pane

## 聊天命令（/ 指令）

| 指令 | 说明 |
| --- | --- |
| `/clear` | 清空聊天历史并清空 Chat Pane 显示 |
| `/reset` | 清空聊天历史并清空 Chat Pane + Exec Pane 显示 |
| `/exit` | 退出 

## 使用场景与应用价值

- 上下文协作：减少复制粘贴上下文的成本
- 排障与定位：基于当前窗口可见信息快速给出根因假设、验证步骤与最小修复建议
- 安全的命令辅助：生成可执行方案并在人工确认后执行，降低误操作风险
- 提效与学习：将你的命令行操作当作“现场”，给出更高效/更稳妥的替代命令与解释，形成可复用的操作范式
